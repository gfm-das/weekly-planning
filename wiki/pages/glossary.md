## Terms

| Term | Meaning |
| --- | --- |
| **AP** | Assistant to the President — a manager role for the whole mission |
| **Area** | Smallest place unit where a companionship serves |
| **Baseline** | Starting database schema file for a fresh install (`000_baseline.sql`), then newer migrations |
| **Beta database** | Name of the main Supabase/PostgreSQL stack — it **is** the real data |
| **Call-ins** | Leadership review of weekly plans (mission → zone → district → area) |
| **Cloudflare tunnel** | Safe way to publish localhost ports under public hostnames without opening the router |
| **Companionship** | Two missionaries who share one weekly plan |
| **Container** | A sealed box Docker runs with one program inside |
| **DA Management** | Data-analyst admin site (roster, accounts, uploads, places, updates) on port 8090 |
| **DataEase** | The product behind the Dashboards tab |
| **District / Zone** | Leadership layers above areas |
| **Docker** | Tool that runs containers on the server |
| **DL / ZL / STL** | District Leader / Zone Leader / Sister Training Leader |
| **DBeaver** | Desktop app to look at the PostgreSQL database |
| **GEMIKO** | Call-ins related view/tooling on the Call-ins page (mission acronym usage) |
| **Glimpse** | Manager-only mission summary on Overview |
| **health.ps1** | Script that checks every part is OK |
| **Key indicators** | The six main weekly numbers (Preach My Gospel) |
| **Migration** | Numbered SQL change to the database (with a rollback partner when provided) |
| **portal-api** | Python/Flask backend behind `/api/` |
| **PR** | Pull request — a proposed code change on GitHub for review before merge |
| **Reporting Sunday** | The week key for plans and numbers |
| **RLS** | Row-level security — database rules that limit which rows a role can see |
| **Roster** | Transfer file that says who serves where |
| **Slidev** | Slide engine used for Presentations |
| **Stewardship** | The slice of the mission (area/district/zone/mission) a person may see |
| **Stub** | Wiki page that is incomplete on purpose |
| **Supabase** | Auth + PostgreSQL stack used by the portal |
| **Updater** | Windows task that applies GitHub updates when someone presses Update in DA Management |
| **Worktree** | Extra Git checkout folder so you never edit the live folder directly |
