    Glossary

    Glossary explains short technical words used in this wiki in plain English.

    Contents
    1. Terms
    2. See also

    Terms

    TermMeaning
    APAssistant to the President — a manager role for the whole mission
    AreaSmallest place unit where a companionship serves
    BaselineStarting database schema file for a fresh install (000_baseline.sql), then newer migrations
    Beta databaseName of the main Supabase/PostgreSQL stack — it is the real data
    Call-insLeadership review of weekly plans (mission → zone → district → area)
    Cloudflare tunnelSafe way to publish localhost ports under public hostnames without opening the router
    CompanionshipTwo missionaries who share one weekly plan
    ContainerA sealed box Docker runs with one program inside
    DA ManagementData-analyst admin site (roster, accounts, uploads, places, updates) on port 8090
    DataEaseThe product behind the Dashboards tab
    District / ZoneLeadership layers above areas
    DockerTool that runs containers on the server
    DL / ZL / STLDistrict Leader / Zone Leader / Sister Training Leader
    DBeaverDesktop app to look at the PostgreSQL database
    GEMIKOCall-ins related view/tooling on the Call-ins page (mission acronym usage)
    GlimpseManager-only mission summary on Overview
    health.ps1Script that checks every part is OK
    Key indicatorsThe six main weekly numbers (Preach My Gospel)
    MigrationNumbered SQL change to the database (with a rollback partner when provided)
    portal-apiPython/Flask backend behind /api/
    PRPull request — a proposed code change on GitHub for review before merge
    Reporting SundayThe week key for plans and numbers
    RLSRow-level security — database rules that limit which rows a role can see
    RosterTransfer file that says who serves where
    SlidevSlide engine used for Presentations
    StewardshipThe slice of the mission (area/district/zone/mission) a person may see
    StubWiki page that is incomplete on purpose
    SupabaseAuth + PostgreSQL stack used by the portal
    UpdaterWindows task that applies GitHub updates when someone presses Update in DA Management
    WorktreeExtra Git checkout folder so you never edit the live folder directly
