Weekly Planning for your mission

Weekly plans, call-ins, the calendar, dashboards and presentations for every missionary and leader, in 14 languages. You install it yourself, on one computer, in about 20 minutes. Your data stays with you.

Version 1.0.3. The file is a small starter: it checks that you have what you need, fetches the newest release and opens the setup page.

What you need

  • A computer that stays on (the mission office's computer is ideal): Windows 10 or 11, a Mac, or Linux. At least 8 GB of memory (16 GB is better) and 40 GB of free disk space.
  • Docker, free: Docker Desktop for Windows and Mac, Docker Engine for Linux. Install it first and start it.
  • Git, free, on Windows: Git for Windows. Mac and Linux usually have it already.
  • An internet connection while installing (the first start downloads about 3 GB).

How it goes

  1. Download the file above for your computer and open it (on Windows: double-click; on Mac and Linux: bash install-weekly-planning.sh in a terminal).
  2. A setup page opens in your browser. Type the mission's name, choose the language missionaries start with, and make the first Data Analyst's account (name, email, password). Everything else on the page is optional. A computer without a screen is asked the same questions in the terminal.
  3. Wait a few minutes while it builds everything: the portal, DA Management, Dashboards, Presentations and the nightly backups.
  4. Open the portal (the address is shown at the end) and sign in with the account you just made.
  5. In DA Management, create the other accounts and upload the roster (Roster Import).

Updates and backups

New versions are published here as numbered releases. In DA Management, the Updates page shows what is new and installs it only when a person asks: it tests the new version first, saves a way back, and checks the system's health afterwards. A backup of the database is made every night.
